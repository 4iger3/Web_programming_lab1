Task 7. Debug the code

During project creation you might encounter errors or problems. Please specify what errors/problems you encountered and solved during Laboratory Work 1. (You may provide answer in a written form below.)
Результат:

Ошибки и решения:

  1. Express version: задание указывало express ^4.17.1, использована ^4.18.2 — совместимость сохранена, все функции работают.
  2. Сервер не запускался: при первом запуске node server.js в фоновом режиме процесс иногда не успевал стартовать. Решение: добавлен sleep 2 перед проверкой через curl.
  3. Скриншоты через Firefox: Firefox в headless mode не всегда делал скриншот корректно. Решение: использован изолированный профиль (--profile /tmp/lab-firefox-profile).

Все задачи выполнены успешно. Сервер работает на порту 3000, сайт доступен по адресу http://localhost:3000.
