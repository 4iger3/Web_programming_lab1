Web Application Development Tools Laboratory Work N1

During this laboratory work you will create your own one page website with dynamical elements using Node.js with Express.js.

Task 1. Install NPM at your local environment.

NPM installation guide: https://docs.npmjs.com/downloading-and-installing-node-js-and-npm

You can use any Node Version Manager (NVM) to set up your project.

To do a check after installation please run the following commands:

node -v
npm -v

Результат:

Node.js v24.21.0 / npm v11.19.0

Task 2. Create New Web App Project (using Node.js with Express.js)

Create a new folder (at the place you want to keep your project).

In our example let's call project: node-lab-website

Create two files inside node-lab-website folder:

  • package.json file
  • server.js file

Create a folder (name: express) and a file inside node-lab-website/express folder:

  • node-lab-website/express/index.html file

After creating above two files, open your terminal in the "node-lab-website" folder and run this command:

npm install

Результат:

Project structure created and dependencies installed:

.
./express
./express/index.html
./node_modules
./package.json
./package-lock.json
./server.js

Task 4. Run Project.

To start a server run this command in terminal:

npm start

To test this API — Open your web browser and enter this URL → localhost:3000

Результат:

Server running on port 3000, HTTP 200 response confirmed.

Task 7. Debug the code

During project creation you might encounter errors or problemr.

Please specify what errors/problems you encountered and solved during Laboratory Work 1.

(You may provide answer in a written form below.)

Результат:

Ошибки и решения:

  1. Express version mismatch: исходное задание указывало express ^4.17.1, но в среде была доступна более новая версия. Заменена на ^4.18.2 — совместимость сохранена.
  2. Сервер не запускался при первом запуске: при запуске node server.js в фоне sometimes процесс не стартовал из-за задержки. Решение: добавлен sleep 2 и проверка curl.
  3. Скриншоты через Firefox headless: Firefox запускался в headless mode, но не всегда делал скриншот. Решение: перезапуск Firefox с флагом --headless и --screenshot.
